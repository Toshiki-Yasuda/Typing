# 手動確認チェックリスト

自動テストでは確認できない、実機のIME・OS・キー配列の挙動を確認する。結果は末尾の表に記入する。

## 準備
```bash
npm install
npm run dev     # 表示された URL を開く（例: http://localhost:5173）
```

## 確認項目（練習画面で行う）
| # | 手順 | 期待される結果 |
|---|------|----------------|
| 1 | IME を**オン**（日本語入力）にしたまま、練習画面でキーを押す | 「日本語入力がオンのようです」と警告が出る。お題は進まない・ミスにもならない |
| 2 | IME をオフ（半角/英数）にして、通常どおり打つ | 打鍵が進み、警告が消える |
| 3 | CapsLock をオンにして打つ | 大文字が入力されても、そのまま進む |
| 4 | Ctrl+R / Ctrl+F / F5 などを押す | ブラウザの動作が妨げられない（ゲームの打鍵にならない） |
| 5 | キーを押しっぱなしにする | 連打にならず、1回だけ入力される |
| 6 | 「ん」を含むお題（例: らーめん）を、`n` 1回で打とうとする | 語末の「ん」は `nn` が必要。`n` 1回では終わらない |
| 7 | 「ー」を含むお題で `-` を押す | 進む |
| 8 | Space・`'`・`/` を含む入力 | ブラウザのスクロール・クイック検索が起きない |
| 9 | 練習を最後まで打つ → 結果 → ブラウザを閉じて開き直す → ホーム | 履歴に残っている |
| 10 | ホームで「書き出す」→ ブラウザのデータを削除 → 「取り込む」 | 記録が元に戻る |
