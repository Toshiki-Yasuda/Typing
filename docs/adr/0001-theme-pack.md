# ADR 0001: テーマパックとパスワード入口

状態: 採用（オーナー確認済み 2026-09-30。一部実装済み）／ 日付: 2026-09-30

## 背景
- コアに固有名詞・原作要素を置かない方針（CLAUDE.md）。世界観は「テーマパック」として分離する。
- オーナーの決定（2026-09-30）:
  1. 最初のテーマは、Ver1（Mobile-）で扱った HUNTER×HUNTER。
  2. 後から別テーマを追加できること。
  3. ゲーム開始時にパスワード `SAKI` を入力して遊べるようにする。
  4. 個人利用なので、著作権は不問とする。

## 決定（案）
### テーマパックの構造
- テーマは `src/themes/<id>/` に置く。コア（engine / metrics / session / storage）は import しない。
- 各テーマは `manifest.json`（zod で検証）を持つ:
  `id` / `name` / `colors`（上書きできるトークンを限定）/ `strings`（見出し・結果のひと言など）/ `assets`（画像・音の相対パス）/ `license`（素材の出所メモ）。
- 中立テーマ（現行の見た目）を既定とし、常に存在する。HUNTER×HUNTER は2つ目のテーマ。
- 読み込み時に検証し、不正・欠落があれば中立テーマへ戻す。色はコントラスト比を検査する（基準未満は中立色）。
- 選んだテーマの ID は**設定**（localStorage）にだけ持つ。記録・統計・級位には持たせない（テーマを変えても記録は変わらない）。

### パスワード入口
- 起動時に入力画面を出し、`SAKI` で通過する。通過の記録は localStorage に持つ（毎回は求めない）。
- 判定はクライアントだけで完結する。公開サイトでは**ソースを読めば分かる**ため、これは鍵ではなく「入口の目隠し」であり、セキュリティ機能とは見なさない（オーナー了承）。平文をソースに置かないよう、SHA-256 のハッシュと比較する。
- 大文字小文字は区別しない。入口は `PageHeading` を持ち、キーボードだけで操作でき、a11y 検査（axe）に加える。
- 入口の範囲: **テーマを開くときだけ**（オーナー決定）。ゲーム自体は誰でも遊べる。ホームの「テーマ」で `SAKI` を入れると HUNTER×HUNTER が選べる。

### 素材の扱い
- 著作権はオーナーが不問とした。ただし `main` は GitHub Pages で**公開**される。素材を同梱すると第三者にも配信されるため、リポジトリに入れるか、手元だけで取り込むかは、オーナーが選ぶ（未決）。
- 素材の出所は `assets/LICENSES.md` に表で残す。

## 未決事項
1. Ver1 のテーマ内容（配色・台詞・画像・音・ボス）の取り込み方（Ver1 のリポジトリを読めるかによる）。

## 実装の順序
1. ✅ 切替の仕組み（`src/themes/`。色は CSS 変数の上書き、コントラスト検証、ロック）
2. ✅ HUNTER×HUNTER テーマ（配色は Ver1 の hunter パレット。画像・音・ボスは未取り込み）
3. ✅ パスワードによるテーマの解除
4. 画像・音・ボス戦（別 ADR）

## ボス戦（初版、2026-09-30）
- ボスはテーマのデータ（`Boss`。zod で検証）。HUNTER×HUNTER は Ver1 の 7 章（名前・台詞）。出題パック・お題の数・ミスの許容は、Ver1 の難易度に合わせてこちらで割り当てた。
- ルール（`src/session/bossBattle.ts`）: お題を 1 つ打ち終えるとボスの HP が 1 減る。ミスが許容（`maxMisses`）を超えると敗北。進み具合でフェーズ 1〜4。ランクは S（ノーミス）/ A（1 ミス）/ B（許容の半分以下）/ C / D（敗北）。**ランクの基準は仮**。
- 入力の判定は `PracticeSession` のまま。ボス戦は結果を受けて HP を動かすだけで、判定・計測は通常の練習と同じ（テストで確認）。打鍵ログは `mode: boss:<id>` の通常の記録として保存する。敗北時は、打ち始めたお題までを記録する。
- 弱点との連動は、出題に `pickAdaptive`（キー・連接の弱点）を使うこと。
- 戦績（挑戦回数・勝利・最高ランク）は localStorage（`typing.boss.v1`）。
- テーマの色検査に、固定色（`--viz-*`）の可読性を追加した。HUNTER の背景は、これを満たすよう Ver1 より少し暗い。
- 画像は Ver1 に実物があった 1・2 章のみ（他は Ver1 でも仮の画像だった）。Ver1 の時間制限・攻撃予告・報酬・BGM は未対応。
