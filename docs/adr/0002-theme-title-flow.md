# ADR 0002: テーマの入口（オープニング・タイトル・ステージ選択・設定）と BGM

状態: 採用（オーナー指示 2026-09-30。段階的に実装する）

## 背景
- ADR 0001 のテーマ（HUNTER×HUNTER）は、配色・効果音・3D・ボス戦まで揃った。次に、**テーマを選んだら「ゲームの入口」から始まる**体験にする。
- Ver1（Mobile-）の構成: パスワード → タイトル（オープニング演出 → メニュー）→ レベル選択 → ステージ選択（7 章 × 6 ステージ、最後がボス）→ 練習 → 結果。設定（BGM/SE 音量、ローマ字ガイド、パーティクル、アクセシビリティ）。BGM は HTMLAudio、ボス戦のフェーズで音量を下げる。
- Ver2 の原則は維持する: コアに固有名詞を置かない／演出は描画だけで打鍵を遅らせない／色だけで伝えない／演出の強さ（標準・控えめ・オフ）に従う。

## 画面の流れ
```
[テーマを選ぶ / 起動時に保存済みテーマ]
        │（テーマに入口がある場合）
        ▼
   /title ──(ゲート: 「Enter でスタート」＝ 音を鳴らす許可を得る)
        │  オープニング演出（飛ばせる）
        ▼
   タイトルメニュー ── はじめる(/play) / ステージ選択(/stages) / 今日のチャレンジ(/daily)
                      / 統計(/stats) / 設定(/settings) / ホーム(/)
```
- **標準テーマ**: 今までどおり（ホームが入口）。オープニングもタイトルも無い。
- **入口が出るとき**: ① ホームでテーマを選んだ直後（解除した直後を含む）② 起動時に保存済みのテーマに入口があり、**この起動（タブ）でまだ見ていないとき**（`sessionStorage` に印）。同じタブで戻ってきても繰り返さない。
- ホーム（`/`）は「記録・データ管理・練習の設定」の拠点として残す。入口からもリンクする。
- Esc: ステージ選択・設定からタイトルに戻る。

## テーマのデータ（`Theme` に足す。コアは固有名詞を持たない）
- `title`: `{ heading, subheading, tagline, logo? }`（見出しの文言・ロゴ画像）。
- `audio`: `{ stinger?, opening?, title?, stage?, play?, boss? }`（BGM と効果音の相対パス。無ければ無音）。
- `chapters`（ステージ選択）: `[{ id, title, subtitle, stages: [{ id, name, description, pack }], boss }]`。`pack` は語彙パック（JSON）の相対パスで、選んだときだけ読み込む。

## 音（BGM）の設計
- **`BgmManager`**（`src/sound/bgm.ts`）: 1 度に 1 曲。`HTMLAudioElement` でストリーミング再生し（長い曲を丸ごと復号しない）、ループ、フェードイン/アウト、曲の切り替え（クロスフェード）、音量、ページが隠れたら一時停止。DOM/React に依存しない核（`AudioLike` を注入してテストする）。
- **自動再生の制限**: ブラウザは、ユーザー操作の前に音を鳴らせない。入口の「Enter でスタート」（ゲート）を、その操作にする。ゲートの前は無音。再生に失敗しても画面は止めない（次の操作で再試行）。
- **設定**（`Settings`）: `bgm`（オン/オフ）、`bgmVolume`、`sfx`（既存の `sound`）、`sfxVolume`、`gameBgm`（練習中の BGM: `off` / `boss`（ボス戦だけ）/ `all`）。**既定は `boss`**（通常の練習は集中のため無音、ボス戦は鳴らす）。音量は 0〜100 の整数。
- **打鍵との分離**: BGM は `<audio>` が別スレッドで復号・再生する。打鍵の判定・計測・描画は BGM の状態を見ない。BGM の開始・停止は画面の切り替わり時だけ。
- **配信量**: BGM は約 26MB（タイトル約 10MB・ステージ約 4MB・ゲーム約 12MB）。標準テーマでは読み込まない。テーマを選んだときも、`preload="none"` で、鳴らす曲だけ取得する。圧縮できる場合は 128kbps 程度に落とす。

## オープニングの状態機械（`src/screens/title/opening.ts`。純関数）
`gate`（ゲート）→ `burst`（光・効果音・3D のカード）→ `title`（ロゴ・メニュー）。
- ゲートで Enter・Space・クリック → `burst`。`burst` は約 2.4 秒で自動的に `title`。どの時点でも Enter・Esc・クリックで `title` に飛ばせる。
- 控えめ・OS が動きを減らす → 動きを外した最後の姿。演出オフ → ゲートを出さず、すぐタイトル（音は最初の操作で鳴らす）。
- 表示は飾り。メニューは通常の `<a>` / `<button>`（Tab・Enter）。番号キー 1〜5 のショートカットも付けるが、フォーカス中の操作要素の Enter を奪わない。

## ステージ選択（`/stages`）
- 章（7）→ ステージ（各 6）の一覧。ステージは**語彙パック**（Ver1 の作品用語を、こちらの JSON + zod に変換して検証: 全語が打てる・重複なし）。最後の項目はボス戦（既存）。
- 表示: 章・ステージ名・説明・**クリア済みの印（文字と形）**・最高ランク（ボス）。ステージのクリア＝そのステージを正確率 90% 以上で打ち切ること（仮の基準）。
- 解放: **初版はすべて開放**。クリア済みの印だけ付ける。順番に解放する制（Ver1 方式）は、設定「順番に解放する」として後から足せる形にしておく。
- ステージの練習は、通常の練習と同じ `PracticeSession`。記録のモードは `stage:<id>`。

## 設定（`/settings`）
- 既存の部品（`ThemeSettings`・`PracticeSettings`）を再利用し、音（BGM/SE の入切と音量、練習中の BGM）と演出の強さを集約する。ホームの設定もそのまま残す（同じ部品）。
- 音量スライダーは `<input type="range">`＋数値表示（色だけに頼らない）。

## 実装の段階
1. **音の基盤**: `BgmManager`、音の設定、BGM 素材（圧縮）、テーマの `audio`。
2. **入口**: `Theme.title`、`/title`（ゲート・オープニング・メニュー）、流れ（テーマ選択後・起動時）、3D のオープニング。
3. **設定画面**: `/settings`（音・演出）。
4. **ステージ選択**: 語彙パックの変換ツールと検証、`/stages`、クリアの印。
5. **練習中の BGM**: `gameBgm` に従い、ボス戦（フェーズで音量を変える）と練習に流す。結果画面の効果音。

## 未決・注意
- ランクやクリアの基準、BGM の音量の既定値は仮。遊んでから調整する。
- 実機の音の鳴り方（自動再生の許可、音量バランス）は、この環境（音が出ない）では確認できない。テストは `AudioLike` の差し替えで行い、実機確認はオーナーに依頼する。
