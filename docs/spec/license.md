# マイライセンス

プレイヤーの「カード」。ハンターネーム（設定）と、記録から計算した戦績を 1 枚にまとめて見せる（テーマに `license` があるときだけ）。
**保存するのはハンターネームだけ**。ほかはすべて記録・戦績から毎回計算する。

## 表示するもの
| 項目 | 元 | 備考 |
|---|---|---|
| ハンターネーム | 設定 `hunterName`（12 文字まで。空なら「未設定」） | 入力欄で変える |
| 級位・星 | 縛りなしの記録の `rankStatus` | 星は級位 20 段階を 4 つずつ束ねて 1〜5 個（`starsOf`）。級位が無ければ星なし |
| 系統 | 縛りなしの記録の 6 軸診断（得意な軸のテーマ上の名前） | 診断できない（点が 3 軸未満）なら「未診断」 |
| ボス討伐 | 戦績（`typing.boss.v1`）の勝利済みボス数 / ボス総数 | |
| ステージクリア | 記録から `stageProgress` | クリア数 / 全ステージ数 |
| 図鑑 | 遭遇・習熟 / 全語 | 図鑑があるテーマのみ |

## 規則
- 星: `starsOf(index)` = min(5, 1 + floor(index / 4))（index は `RANKS` の 0 始まり）。
- 数の表示は分数（例「3 / 7」）。色だけで示さない。星は文字（★）と数（「星 3 つ」）で示す。
- カードは HTML（読み上げられる）。3D のカードは飾り（`aria-hidden`）で、演出の強さに従う。
