# 修行の型（絶・練・発）と補助（凝・円）

練習の「型」。**判定・計測は通常の練習と同じ**（`PracticeSession`）。型は、出題・終わり方・表示・結果の見せ方だけを変える。
記録のモードは `train:<型>`（`train:zetsu` / `train:ren` / `train:hatsu`）。通常の統計・級位にも数える（打鍵は普通の打鍵のため）。

| 型 | 名前（標準の言葉） | 出題 | 終わり | 結果の指標 |
|---|---|---|---|---|
| 絶 zetsu | 静寂 | 設定の語数（弱点優先） | 全語を打ち終える | **ミス数**で段階（S:0 / A:1〜2 / B:3〜5 / C:6〜）。音・演出・運指ガイドを出さない |
| 練 ren | 速さ | 語を多め（パックの全語まで）に用意 | **60 秒**たつ（注入した経過時間で判定）。最初の打鍵からではなく**開始から** | 打ち切った**語数**と速度 |
| 発 hatsu | 弱点 | 弱いキーを含む語を、多く含むものから | 全語を打ち終える | 型の名前（例「『k』の型」）と、ミス |

## 発（弱点からの技）
- 弱点は `keyWeakness`（セッションごとに集計して合算）。上位 3 キーを「技のキー」にする。
- 語の得点 = 最短経路のキーのうち、技のキーの弱さの合計。得点の高い順に語数だけ選ぶ（同点は乱数）。得点 0 の語は、足りないときだけ埋めに使う。
- 名前は、最も弱いキーから付ける: `『k』の型`。記録が無い（弱点が求まらない）ときは発を始めず、案内を出す。

## 練（時間制限）
- 残り時間は純関数 `remainingMs(startMs, nowMs, limitMs)`（0 未満にならない）。画面はこれを表示するだけ。
- 時間切れの後の打鍵は記録しない。切れた時点までの記録を保存する（途中のお題は含む）。
- 打ち切った語数は `wordsCompleted`。**最後に打ち始めた語は含めない**（未完了のため）。

## 補助（判定に影響しない表示だけ。設定でオン/オフ）
- **凝 gyo**: 弱点上位のキーを、ローマ字ガイドの中で強調（太字＋点線の下線。色だけにしない）。
- **円 en**: 次のお題を、小さく先に見せる（最後のお題では出さない）。

## テーマの言葉
標準の言葉で動く。テーマは `train.names` / `train.aids` で言葉（HUNTER は 絶・練・発／凝・円）を差し替える。
