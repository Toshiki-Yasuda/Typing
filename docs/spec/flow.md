# 終わった後の動線（結果画面）

ステージ・ボス戦が終わったとき、「次に何をするか」をゲームの流れとして示す。純関数は `src/session/afterFlow.ts`、画面は `src/screens/AfterActions.tsx`（結果画面 `Result.tsx` が使う）。

## 原則
- **先へ進むのが主役。** 主ボタン（大きい）は、状況で最も自然な次の行動。副は小さく。
- **ステージ・ボスの文脈から外さない。** ステージ・ボスの結果には、「新しいお題で練習」「同じお題でもう一度」（ふつうの練習になり、ステージのクリアに数えられない）を出さない。
- 主ボタンは**結果の数字より上**（画面内）に置く。数字は下。
- キー: **Enter＝主ボタン、Esc＝戻り先**。押しっぱなし・修飾キー併用・IME 変換中は無視する。フォーカス中のリンク・ボタンの動作は奪わない（ホームの Enter と同じ判定）。キーの案内は画面に文字で示す。

## 行き先の表
| 状況 | 主ボタン（Enter） | 副 | Esc |
|---|---|---|---|
| ステージをクリア、次のステージがある | 次のステージ | もう一度このステージ／ステージ選択へ | ステージ選択 |
| クリア、章の最後、章のボスがある | この章のボスに挑戦 | 同上 | ステージ選択 |
| クリア、最後でボスも無い | ステージ選択へ | もう一度このステージ | ステージ選択 |
| クリアならず | もう一度このステージ | ステージ選択へ | ステージ選択 |
| ボスに勝った、次の章がある | 次の章へ（次の章の最初のステージ） | もう一度挑戦／ステージ選択へ | ステージ選択 |
| ボスに勝った、最後の章 | ステージ選択へ | もう一度挑戦 | ステージ選択 |
| ボスに負けた | もう一度挑戦 | ステージ選択へ | ステージ選択 |
| ボス（勝敗が不明。履歴から開き直した） | ステージ選択へ | もう一度挑戦 | ステージ選択 |
| ふつうの練習・修行・デイリー | 同じお題でもう一度 | 新しいお題で練習／ホーム（従来どおり、下に並べる） | ホーム |

- 「クリア」は、正確率が基準以上、かつ縛り「ミスなし」が破れていないこと（`stageProgress` と同じ）。
- ステージ・ボスの結果の下には、ホームへのリンクだけを残す。

## 中断
- ステージ・ボス戦の練習中の Esc・「中断」ボタン・1 打もないままの終了は、**ステージ選択**へ戻る（`Play` の `exitTo`）。ふつうの練習・修行・デイリーはホーム（既定）。

## ステージ選択
- 縛りと「順番に開放する」は `<details>`（ルール設定）に折りたたむ。見出しに、いまの状態（縛りの数・順番開放のオン/オフ）を文字で出す。ステージ一覧は最初から画面内に見える。
