# 級位・目標の仕様 v1

練習の進み具合を、実効速度（KPM）の段階で示す。段階の値は**仮置き**で、使いながら調整する。実装は `src/metrics/rank.ts`（この表とテストで一致を検査している）。

- 実効速度は `docs/spec/metrics.md` の定義（お題の中の打鍵間隔で測る）。
- 速度に対応する級位は、この表で「その速度以上」の最も高い級位（境界の値は上の級位に入る）。

## 現在の級位
- **判定に数える練習**: 正確率が基準以上で、打鍵が最低数以上のもの。雑に速く打っても級位が上がらないようにする。
- **現在の級位**: 判定に数える直近 N 回の実効速度の**中央値**に対応する級位（1回だけ調子が良くても上がらず、1回だけ悪くても下がらない）。
- 判定に数える練習が認定回数に満たない間は「暫定」と表示する。数える練習が1回も無ければ、級位は無い。

| パラメータ | 値 | 意味 |
|---|---|---|
| RANK_MIN_ACCURACY | 0.95 | 判定に数える練習の最低の正確率 |
| RANK_MIN_KEYSTROKES | 20 | 判定に数える練習の最低の打鍵数 |
| RANK_WINDOW | 5 | 現在の級位を決めるために見る、直近の数える練習の回数 |
| RANK_CERTIFY_COUNT | 3 | これ未満なら「暫定」 |

## 昇級
練習を1回終えるたびに、その練習を含めた現在の級位が、含める前より高ければ「昇級」と知らせる。初めて級位が付いたときも知らせる。下がった場合は知らせない（現在の級位だけ示す）。

## 目標
- 設定で「自動（次の級位）」または特定の級位を選ぶ。既定は自動。
- 自動は、現在の級位の次の級位（最上位なら現在の級位）。
- 目標までの差 = 目標の必要な速度 − 現在の級位の元になった速度（中央値）。0 以下なら達成済み。

## 未確定（要確認）
- 段階の値の妥当性（使いながら調整する）。日本語のタイピング検定の基準（10分間の入力文字数）とは、単位も測り方も違うので、そのまま対応させてはいない。
- 正確率の基準（95%）は、根拠を確認できていない仮値。
