# ボス戦の仕様

ボスはテーマのデータ（`Boss`、zod）。戦闘のルールはコード（`src/session/bossBattle.ts`、純関数・時計なし）。
**入力の判定・計測は通常の練習と同じ**（`PracticeSession`）。ボス戦は、ボスの体力・敗北条件・表示だけを足す。

## 基本（実装済み）
- ボスの体力 = お題の数。お題を 1 つ打ち終えると 1 減る。全部で勝利。
- ミスが許容（`maxMisses`）を**超える**と敗北。フェーズは体力の減りで 1〜4。
- ランク: S=ミス 0 / A=ミス 1 / B=許容の半分以下 / C=それ以上 / D=敗北（**ミスの総数**で決める）。

## 時間制限（`Boss.timeLimitSec`、任意）
- 経過時間は入力として渡す（`tick(elapsedMs)`）。`BossBattle` は時計を持たない。時間切れで敗北（理由は「時間切れ」）。
- 残り時間は文字で表示する（色だけにしない）。既定は無制限。**上位の章（5・6・7）だけ**に付ける（値は仮）。
- 時間切れの記録は、そこまでの打鍵を通常のボス戦の敗北と同じに保存する。

## ボスの技（`Boss.skill`、任意）— 弱点への働きかけ
判定は変えない。表示と敗北条件にだけ作用し、設定 `bossSkills`（既定オン）で**無効にできる**（アクセシビリティ）。
| 技 | ボス（HUNTER） | 作用 | 弱点との結びつき |
|---|---|---|---|
| `hide` | ヒソカ | お題が 3 つに 1 つ（0 始まりで 2・5・8…番目）、ローマ字ガイドの**残り**が「・」になる（打った分は見える） | 先を読む力・キーを覚えている力 |
| `strip` | クロロ | 直前のお題でミスをしたら、次のお題は運指ガイドを出さない | ミスしたあとの立て直し |
| `stamina` | ビスケ | 正しい打鍵が 10 連続するごとに、ミスを 1 回ぶん回復する（初期の許容まで）。ランクは回復前を含む**ミスの総数** | 落ち着いて連続で打つ力 |
- 技の名前と説明はテーマのデータ（`skill.name` / `skill.text`）。戦闘中に文字で示す。

## 報酬
- 戦績（`typing.boss.v1`）に、勝利したときの**最大の縛りの数** `bestVows` を持たせる（任意項目。無い旧データはそのまま読める）。
- メダル: 縛り 1=銅・2=銀・3 つ以上=金（`docs/spec/vows.md`）。ボス一覧・ステージ選択・結果に文字で示す。

## 攻撃予告（`Boss.attacks`、任意。N6b）
純関数は `src/session/bossAttacks.ts`（時計を持たない。経過時間は呼び出し側が渡す）。
- `attacks: { everyWords, windowSec }`。`everyWords` 語ごとの 1 語（0 始まりで 番号 % everyWords === everyWords - 1）が**予告の語**になる。乱数は使わない。
- 予告の語が**出た時点**から `windowSec` 秒以内に打ち終えれば回避。前の語にかけた時間は数えない。
- 間に合わなければ、戦闘の**ミスを 1 回**受ける（同じ語で 2 回は受けない）。ミスの余裕が尽きれば敗北。打鍵ログには入らない（判定・計測は変えない）。ランクの「ミスの総数」には数える。
- 表示は文字で「攻撃予告：残り N.N 秒（間に合わないとミス扱い）」。予告の語でなければ「この語は予告なし」。受けたら台詞欄に「攻撃を受けた！」。
- 設定 `bossSkills`（既定オン）でオフにできる（技と同じ。アクセシビリティ）。
- HUNTER: 章 2（3 語ごと・8 秒）と章 5（4 語ごと・15 秒＝長文の語）。**値は仮**。
