# 図鑑

テーマの語彙のうち、**キャラクター・能力・道具・場所・組織**の語（Ver1 の 287 語）を見出しにして、「出会った」印と習熟を示す。
初版は**名前と習熟だけ**。説明文は、原作の記述の正確さを確認できたものだけ、少しずつ別に足す（量で押さない）。

## データ
- `public/themes/hunter/codex.json`（`art/hunter/extract_codex.py` で Ver1 から生成。手で編集しない）。`{ entries: [{ display, reading, category, chapter }] }`。
- 読み込み時に検証する: 読みが打てる／（表記・読み）の重複なし／区分は 5 種のみ。テーマの `codex.path` と区分の呼び名 `codex.categories` で参照する。

## 進み具合（記録から計算。保存しない）
- 対象の記録は、**縛りなし**（`plainRecords`）。語の照合は、記録の `targets[item]`（正規化した読み）と見出し語の正規化した読みの一致。
- 語ごとに、`typed`（その語を打ち始めた回数 = 記録ごとの語の出現）・`attempts`（その語の打鍵数）・`misses`・正確率を数える。
- 段階（文字でも示す）:
  - **未遭遇**: typed = 0（名前は伏せる「？？？」。章だけ示す）。
  - **遭遇**: typed ≥ 1。
  - **習熟**: typed ≥ 3 かつ 正確率 ≥ 95%（`RANK_MIN_ACCURACY` と同じ基準）。
- 同じ読みの見出し語は、同じ進み具合を共有する（記録は読みで持つため）。

## 画面 `/codex`
- 見出し「図鑑」。上に「遭遇 X / 全 N・習熟 Y」。区分で絞る（すべて／各区分。`aria-pressed`）。
- 語の一覧は、表示・読み・段階（「習熟」「遭遇」「未遭遇」）・打った回数と正確率。色だけで段階を示さない。
- 入口: タイトルのメニュー（テーマに図鑑があるとき）、ホーム。
