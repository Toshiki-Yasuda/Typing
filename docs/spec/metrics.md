# 計測仕様 v1（ドラフト）

## 1. 記録するもの（打鍵ログ）
生の打鍵を記録し、指標はログから純関数で再計算する。判定や式を変えても過去分を再計算できる。

```
Keystroke { t: number, key: string, code: string, expected: string | null, correct: boolean }
Session   { id, startedAt, mode, contentId, engineVersion, ruleVersion, keystrokes[] }
```
- `t` は `event.timeStamp` ベースの、セッション開始からの相対ミリ秒。
- 絶対精度はハード・OSに依存するため保証しない。**相対比較用**と明記する。

## 2. 指標の定義
- 総打鍵 = 全 keydown（除外条件を除く）。正打鍵 = 期待どおりだった打鍵。誤打鍵 = それ以外。
- **正確率** = 正打鍵 / 総打鍵。
- **実効速度（KPM）** = 正打鍵 / 経過分。**raw 速度** = 総打鍵 / 経過分。
- 参考表示: 文字/分、WPM換算（KPM ÷ 5）。
- **開始** = 最初の打鍵。**終了** = 最後の正打。表示前の待機時間は含めない。
- **一貫性** = 打鍵間隔の変動係数（標準偏差 / 平均）を 0〜100 に写像。
- ミス直後の打鍵の遅延は、キー別遅延の統計から**除外**する（推定を汚さないため）。
- 「効率」= 理論最小打鍵数 / 実打鍵数（経路を選ぶ効率を見る）。

## 3. 除外する入力
`event.repeat` / IME変換中（`isComposing` または `keyCode 229`）/ Ctrl・Alt・Meta 併用 / 修飾キー単独。

## 4. 統計（個人用）
日・週の推移（実効速度・正確率・一貫性）/ キー別ヒートマップ（遅延・ミス率）/ 連接（bigram）別遅延 / 期待キー→実打鍵の混同行列 / 連続日数 / 時間帯（件数併記）。

## 5. 未確定（要確認）
- 一貫性の写像式、正確率の警告閾値（初期値は仮置き。使いながら調整する）。
- 打鍵時刻の丸め精度の実測。
