# 計測仕様 v1

## 1. 記録するもの（打鍵ログ）
生の打鍵を記録し、指標はログから純関数で再計算する。判定や式を変えても過去分を再計算できる。

```
Keystroke { t: number, key: string, code: string, expected: string | null, correct: boolean }
Session   { id, startedAt, mode, contentId, engineVersion, ruleVersion, keystrokes[] }
```
- `t` は `event.timeStamp` ベースの、セッション開始からの相対ミリ秒。
- 絶対精度はハード・OSに依存するため保証しない。**相対比較用**と明記する。

## 2. 指標の定義
- 総打鍵 = 全 keydown（除外条件を除く）。正打鍵 = 期待どおりだった打鍵。誤打鍵 = それ以外。
- **正確率** = 正打鍵 / 総打鍵（打鍵ゼロなら 100%）。
- **区間（interval）**: 同じお題の中で連続する2打鍵の間。次のお題を読む時間（お題をまたぐ間隔）と、**休止**（`PAUSE_MS` = 3000ms を超える間隔）は区間に含めない。
- **打鍵時間（activeMs）** = 区間の長さの合計。
- **実効速度（KPM）** = 正打で終わる区間の数 / 打鍵時間（分）。**raw 速度** = 区間の数 / 打鍵時間（分）。
  - n 打鍵は n−1 個の区間にまたがるので、打鍵数ではなく**区間の数**で数える（打鍵数で割ると、短いお題ほど速く出る）。
  - ミスの区間は時間には入るが「進んだ数」には入らない。ミスは速度を下げる。
  - お題ごとの最初の打鍵は、その前の区間が無いので速度に寄与しない（読む時間の影響を受けないため）。
- **所要時間（elapsedMs）** = 最初の打鍵から最後の正打まで。表示用で、お題の間の待ちを含む。速度には使わない。
- 参考表示: WPM換算（KPM ÷ 5）。
- **一貫性** = 統計に使える連続2打鍵（下記）の間隔の変動係数 `cv`（標準偏差 / 平均）を `100 × (1 − tanh(cv))` で 0〜100 に写す。間隔が3つ未満なら算出しない。
- **統計に使える連続2打鍵（cleanPairs）** = 同じお題の中で、直前・当該とも正打で、休止でないもの。
  ミス直後の打鍵（ミス後の減速）と訂正の打鍵は、遅延の推定を汚すので、キー別・連接別の遅延と一貫性から**除外**する。
- 「効率」= 理論最小打鍵数 / 総打鍵（経路を選ぶ効率を見る）。
- 複数セッションの統計は、**セッションごとに求めて合算**する（セッションの境界をまたぐ偽の連続2打鍵を作らないため）。

## 3. 除外する入力
`event.repeat` / IME変換中（`isComposing` または `keyCode 229`）/ Ctrl・Alt・Meta 併用 / 修飾キー単独。

## 4. 統計（個人用）
時間帯・曜日別は、練習を**始めた時刻**（実行環境のローカル時刻）で振り分ける。速度は、速度を計算できた練習の平均。ミス率は 練習ごとの「ミス/総打鍵」の平均。回数が `MIN_SAMPLE`（3）未満の区分は参考値。「最良」の区分は、3回以上の区分が2つ以上あるときだけ示す。


日・週の推移（実効速度・正確率・一貫性）/ キー別ヒートマップ（遅延・ミス率）/ 連接（bigram）別遅延 / 期待キー→実打鍵の混同行列 / 連続日数 / 時間帯（件数併記）。

## 5. 未確定（要確認）
- 正確率の警告閾値（初期値は仮置き。使いながら調整する）。
- ウィンドウが非アクティブの間の扱い（`blur` / `visibilitychange` でポーズするか。task.md の P0）。
- 打鍵時刻の丸め精度の実測。
