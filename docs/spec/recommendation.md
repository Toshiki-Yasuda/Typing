# 練習の推奨

記録から、次にやると良い練習を 1 行で提案する。**提案するだけで、計測・級位は変えない。**

## 規則（`src/session/recommendation.ts`、純関数 `recommendation(summaries)`）
- 対象: 打鍵が `RANK_MIN_KEYSTROKES`（20）以上の練習の、**直近 3 回**（開始時刻順）。3 回に満たなければ提案しない。
- **丁寧さ（careful）**: 3 回の正確率の**中央値**が `RANK_MIN_ACCURACY`（95%）未満 → 「速さより、ミスなく打つ」。行き先は修行の絶（静寂）。
- **速さ（speed）**: 3 回の**すべて**が 95% 以上 → 「速さに挑戦」。行き先は修行の練。
- どちらでもない（中央値は基準以上だが、1 回だけ未満）→ 提案しない（1 回の好不調で動かさない）。
- 文言には根拠の数値（中央値の正確率・基準・回数）を含める。

## 出し方（過度に出さない）
- ホーム: 提案があれば 1 行（丁寧さ・速さ）。
- 結果画面: **丁寧さのときだけ**、かつ**今回の練習自体が基準未満**のとき。速さの提案は結果画面では出さない（毎回の助言にしない）。
- 級位の判定に数えない練習（20 打鍵未満）は、どちらの判定にも使わない。
