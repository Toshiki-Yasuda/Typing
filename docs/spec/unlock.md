# ステージの順番解放

設定 `stageUnlock`（`'all'` | `'sequential'`、既定 `'all'`）。**既定では従来どおり、すべて開いている。**

## 規則（`sequential` のとき。`src/session/stageUnlock.ts`）
- ステージを、章の順・章の中の順に 1 列に並べる（全章で通しの順）。
- **最初のステージは常に開いている。** それ以外は、**直前のステージがクリア済み**のとき開く（クリアは `isStageCleared`。縛り付きのクリアも数える。「ミスなし」が破れた記録は数えない）。
- 章のボスは、**その章のステージがすべてクリア済み**のとき開く。
- 一度クリアすれば、記録が残る限り開いたまま（記録から毎回計算する。保存しない）。

## 表示・動作
- 閉じたステージ・ボスは、リンクにせず、無効の項目（`aria-disabled`）にして「🔒 前のステージをクリアで開く」/「🔒 この章のステージをすべてクリアで開く」と文字で示す。
- URL を直接開いても（`/stage/:id`・`/boss/:id`）、閉じていれば練習せず、理由とステージ選択への案内を出す。
- `all` のときは、判定しない（従来と同じ）。
- 設定の切り替えは、ステージ選択の画面（縛りの下）に置く。ホームのボス一覧も、同じ判定に従う。
