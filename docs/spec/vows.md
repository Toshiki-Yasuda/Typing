# 制約と誓約（縛り）

ステージ・ボス戦を始める前に、任意の縛りを選ぶ。縛りを付けて**クリアすると、メダルが上がる**。
縛りは、**表示と終わり方**にだけ作用する。**入力の判定・計測は変えない**（`PracticeSession` は同じ）。

| id | 名前（標準の言葉） | 作用 |
|---|---|---|
| `noRomaji` | ローマ字を隠す | ローマ字ガイドの文字を「・」に。読みと表示は見える |
| `noFinger` | 運指ガイドなし | 運指ガイドを出さない |
| `noMiss` | ミスなし | 1 回でもミスしたら、そこで終わる（ボス戦は許容 0） |
| `silent` | 無音 | 効果音・BGM・段階到達の音を出さない |

## 適用範囲
- ステージ（`/stage/:id`）とボス戦（`/boss/:id`）。通常の練習・デイリー・修行には適用しない（比較や型の意味が変わるため）。
- 選んだ縛りは設定 `vows` に保存し、ステージ選択とホームのボス一覧で変える。

## 記録の印と集計
- 記録（`SessionRecord`）に `vows`（id の配列、正規の順）を持たせる。空なら持たない。**保存形式の版を 2 に上げる**（`migrate` は版だけ上げる）。
- **縛り付きの記録は、級位・統計・6 軸診断・練習の推奨・弱点の集計・ゴーストに数えない**（`plainRecords`）。速度や正確率が、縛りで通常とは別物になるため。
- 統計画面に、数えなかった件数を文字で示す。結果画面に、数えない旨を示す。

## メダル（文字でも示す）
- 縛りの数: 0=なし / 1=銅 / 2=銀 / 3 つ以上=金。
- ステージのメダルは、**クリアした（正確率 90% 以上）記録のうち最も縛りの多いもの**。記録から計算する（保存しない）。
- 「ミスなし」を付けた記録で、ミスがあった（＝途中で終わった）ものは、クリアに数えない（メダルなし）。
