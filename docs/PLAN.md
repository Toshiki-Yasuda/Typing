# Ver.2 計画

Ver.1（Mobile-）の調査結果を踏まえた作り直し計画。詳細な調査内容は Mobile- の `docs/V2_PLAN.md` を参照。

## 決定事項
| 項目 | 決定 |
|---|---|
| 方針 | コアを先に堅牢に作る。モチーフ・テーマは別に用意し、後から載せる |
| 用途 | 個人学習用（公開・収益化は想定しない） |
| 対応環境 | **PC専用**（物理キーボード）。スマホ・PWA・仮想キーボードは対象外 |
| リポジトリ | 新規（本リポジトリ）。Ver.1は保全 |
| 運用 | 雛形のみ `main` 直コミット。以後は機能ブランチ＋CI必須 |

## 設計原則
- **コアにIP要素を入れない**。名称・台詞・画像・音源はテーマパックに分離する
- **エンジンは UI 非依存**（DOM/React 依存なし）。`src/engine/` に置き、必要になったら独立パッケージ化する
- **コンテンツはデータ駆動**。語彙・ステージ・ボスを JSON/YAML＋zod で定義し、CIで検証する
- **CIを最初から必須にする**（lint・型・テスト・ビルド）。Ver.1は CI にテストが無くビルド不能のまま main に入った
- デザイントークンは `src/index.css` の `@theme` に一元化する。`prefers-reduced-motion` は最初から対応する

## ロードマップ
| Phase | 内容 | 完了条件 |
|---|---|---|
| 1. 基盤 | 雛形、CI、デザイントークン | `npm run check` とCIが緑（**完了**） |
| 2. エンジン | ローマ字エンジン再構築（正規化層、「ん」「っ」「ー」の規則のデータ駆動化、判定と表示ガイドの一本化、undo、数字・英字・記号） | Ver.1の92テスト移植＋パターン表の総当りテスト全緑。語末「ん」等の仕様を固定 |
| 3. コア画面 | 型付きルーティング、タイピング画面、結果、進捗・統計、設定（永続ストアは key/version/migrate を一元化） | PCで通しプレイ可能 |
| 4. コンテンツ基盤 | スキーマ(zod)、検証CI、難易度の自動算出（打鍵数・ローマ字複雑度）、中立テーマで動作 | テーマ差し替えで動く |
| 5. ボス戦 | 攻撃パターン/フェーズ駆動、演出、報酬、バランス検証 | 全ボスがデータ定義で動く |
| 6. テーマパック | 別途用意するテーマを載せる | — |

## Ver.1から持ち越すもの
- ローマ字エンジンの骨格（状態機械＋前方一致）、パターン表の大半、テストケース
- ボス戦の状態機械（`idle→intro→battle→phaseTransition→finishing→result`）の発想
- 持ち越さないもの: 原作由来の名称・台詞・画像・音源、自前ルーティング、二重管理の統計/ボス記録

## 未確認事項（Phase 2で確定させる）
- 語末「ん」を `n` 単独で打った場合の確定挙動
- `を`→`o`、`ぢ/づ`→`zi/zu` を許容するか
- 長音「ー」を母音キーで受理する独自仕様を残すか
